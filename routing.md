# Маршрутизация (модель/инструмент ↔ задача)
| Задача | Чем | Почему | Эскалация |
|---|---|---|---|
| Расчёты, мощность, выборки | Python (`tools/`) | воспроизводимо, 0 токенов | ошибка кода → показать человеку |
| Классификация источников/тикетов, извлечение чисел, форматирование | младшая/быстрая модель | дёшево, проверяемо | расхождение при выборочной проверке >5% → средняя |
| Исследование, сопоставление источников | средняя модель + поиск/чтение | баланс | противоречия источников → сильная |
| Синтез вариантов и стратегий | сильная модель | цена ошибки высока | — |
| Red-team | другая модель или чистый контекст | независимость | — |
| Фактчек чисел | `sp.py check` + `econ.py` + младшая модель | механическая сверка | — |
Правило: сначала скрипт, потом дешёвая модель, потом сильная. Исправление выбора: если проверка не прошла дважды — подняться на ступень выше и записать в log.
Ограничение: переключение моделей делает человек/среда; агент рекомендует и пишет в журнал. Специализированные модели-оценщики (классификаторы по признакам) подключаются сюда же, если доступны.
