# Экономика
Δприбыль = (Δоплаченные месяцы × ставка) + прочие доходы/экономия − новые прямые расходы. Объём, цена, период у каждого слагаемого.
Срок: сколько месяцев года остаётся после запуска (запуск в последнем месяце → максимум 1 доп. месяц на номер).
Удержание проверяется по платежам когорт, а не по «меньше перебоев». Граница решения: сколько доп. месяцев нужно для цели; предельные вложения;
что при слабом спросе/удержании/дорогом обслуживании. Стоимость разработки — отдельно; если неизвестна — предельная сумма, которая окупится. Всё — `tools/econ.py`.
