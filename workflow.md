# Процесс и критерии выхода
| Этап | Выход | Критерий выхода |
|---|---|---|
| S0 Постановка | outputs/00 (рамка) в STATE.md: вопрос, цель, получатель, решение и срок, ограничения, данные | ≤3 решающих вопроса заданы; остальное — допущения A- |
| S1 Материалы | sources/ + sources.csv; факты E- со ссылкой | каждый источник проверен `ingest` (хэш, подозрительные фразы) |
| S2 Исследование | outputs/01_situation.md | план от вопросов, меняющих решение; пробелы названы; приоритет проблемы сопоставлен с альтернативой |
| S3 Варианты | outputs/02_options.md | ≥3 разных варианта, «оставить как есть», возражения, факты≠гипотезы |
| Ворота A | решение человека → decisions.csv | выбранное направление и отказы записаны |
| S4 Стратегии | 03 продуктовая, 04 коммуникационная, 05 проверка, 06 экономика, 07 ресурсы/риски | согласованность: обещания ≤ продукт; расчёт воспроизводим |
| S5 Самопроверка | отчёт red-team и fact-checker, правки | `sp.py check` без ERROR |
| Ворота B | приёмка человеком | |
| S6 Передача | decisions.csv: решение, основания, ответственный, показатель, условие пересмотра | |
| S7 Пересмотр | список затронутых выводов, обновлённые версии | `sp.py revisit` выполнен |
Остановка возможна на любом этапе: состояние — в STATE.md; продолжение — `/resume`.
