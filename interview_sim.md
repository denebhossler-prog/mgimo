# Интервью и модельные респонденты
**Реальные интервью:** согласие, код респондента, без персональных данных. Гайд: недавний случай (последний раз, когда связь прервалась / было непонятное списание) → хронология → кто заметил первым → что сделали → чем закончилось →
что хотели бы знать раньше. Не спрашивать «понравится ли»; для платного — цена при бесплатной альтернативе.
**Модельные респонденты (ИИ в роли):** только для отладки вопросов, поиска формулировок и гипотез. Каждый ответ → `ev synthetic`.
Нельзя: цитировать как данные клиентов, делать вывод о спросе/распространённости (check это блокирует). Выход: список гипотез H- и правок гайда.
