# S1 Материалы
Для каждого файла/сайта: `ingest` (хэш, происхождение, проверка на инъекции) → извлеки существенные сведения → `ev fact` с `--source SRC-xx --locator "стр./раздел"`.
Таблицы: сохрани единицы, период, знаменатель. Сайты — только разрешённые и открытые; URL и дата доступа в locator.
Дешёвая модель извлекает, выборочно перепроверь 10% записей.
