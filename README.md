# Стратег Фабрики продуктов — репозиторий ИИ-агента

Папка с инструкциями, знаниями и инструментами; открывается в Cursor / Claude Code / Codex / OpenCode / Copilot.
Автономного сервиса нет: агент — это LLM вашей среды + `AGENTS.md` + навыки + скрипты состояния и расчётов.

## Запуск (≈2 минуты)
Требуется: Python ≥3.9 (без сторонних пакетов), IDE-агент с доступом к файлам и терминалу. Ключи и платные сервисы **не нужны**.
```
python tools/tests/test_tools.py                                  # самопроверка инструментов
python tools/sp.py status --brief                                 # что сейчас: этап, следующий шаг, расход
python tools/econ.py projects/family-connect-demo/model/params.json --grid   # расчёт демо
python tools/sp.py check --project family-connect-demo            # проверка ссылок и статусов в выводах
```
Новая задача: откройте папку в агенте и напишите `/new` (Claude Code) либо «Начни проект по брифу …» (другие среды — агент прочитает AGENTS.md сам).
Продолжить после перерыва или в новом чате: `/resume` (или «продолжи»): агент читает `state/STATE.md`. Остановить — просто напишите «стоп»/правку; состояние сохранено.

## Устройство
| Требование | Где |
|---|---|
| Рабочий процесс с воротами | `AGENTS.md`, `knowledge/workflow.md`, `skills/01–08` |
| Порядок в знаниях (4 слоя) | инструкции `AGENTS.md` · методика `knowledge/` + `skills/` · материалы `projects/*/sources`, `evidence.csv` · состояние `projects/*/state` |
| Продолжение | `STATE.md` + хук `SessionStart` + `/resume` |
| Прозрачность | `log.jsonl` (шаг, модель, токены, USD), `evidence.csv` (ID, статус, источник), `decisions.csv` |
| Доп.: интервью и ИИ-респонденты | `skills/interview_sim.md`; S-записи блокируются `check` как основание спроса |
| Доп.: анализ данных | `tools/econ.py`, `tools/power.py` — воспроизводимо, тесты |
| Доп.: поддержка решений, пересмотр | `decisions.csv` (ответственный, показатель, `review_trigger`), `sp.py revoke/revisit` |
| Доп.: маршрутизация | `knowledge/routing.md` (правило, не автопереключатель) |
| Доп.: навыки, хуки, субагенты | `skills/`, `.claude/settings.json`, `.claude/agents/` (red-team, fact-checker) |
| Безопасность | `ingest` ищет команды в источниках; `hook-pre` защищает правила; `.env` в `.gitignore` |
Переносимость: всё — обычные файлы; `.cursor/rules` и `CLAUDE.md` указывают на один `AGENTS.md`; хуки — опциональная надстройка Claude Code.

## Демо-проект
`projects/family-connect-demo/` — бриф «Связь для близких и собственных устройств» (учебный, вымышленный оператор).
Читать с `outputs/00_executive_summary.md`. Основные выводы и ограничения — там же.

## Честные ограничения
- Демо собрано в одной сессии чата с ИИ; поиска по сайтам нет (бриф самодостаточен, внешние данные не нужны). Реальных интервью и данных оператора нет —
  все параметры экономики и пилота помечены допущениями A- и подлежат замене на данные оператора (`projects/*/model/params.json`).
- Расход: токены и время сессии не измерялись автоматически — в `log.jsonl` поля пустые. Сравнение с ручной работой/обычным чатом не проводилось.
- Маршрутизация моделей — рекомендация в журнале, не автоматическая. Хуки проверены только как скрипты (через тесты функций), не в живой среде Claude Code.
- Синтетические интервью — демонстрация процедуры, не данные.

## Известные ограничения проверки `check`
Проверка ссылок и статусов — эвристика: она ловит несуществующие/отозванные ID и строки, где синтетический S- стоит рядом со словами «спрос/распространённость/доля клиентов»
(возможны ложные срабатывания, например «без спроса» — переформулируйте). Она не заменяет чтение вывода человеком.
